"dinner" came out as "divorce" — and the sender signs off cheerfully anyway.

Entry for the make.fun bounty [Funniest Autocorrect Fail](https://make.fun/bounty/u-zeroxfive-funniest-autocorrect-fail-ddf82154).

## Run

```sh
python3 main.py
```

It validates the line (exactly one line, one sentence, 1–199 characters),
writes it to `/output/entry.txt`, and verifies the round-trip.
